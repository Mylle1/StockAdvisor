# StockAdvisor

StockAdvisor is currently a **Nordnet import + fundamentals + valuation CLI toolkit**.

This repository no longer contains Saxo integrations. The current codebase focuses on a local, file-driven workflow:

1. Import holdings from a Nordnet report.
2. Map holding names to exchange tickers.
3. Fetch fundamentals with Yahoo Finance.
4. Run valuation from holdings price + fundamentals data.

---

## Current project status

Implemented and available now:

- Nordnet report import CLI.
- Ticker mapping CLI.
- Fundamentals fetch CLI (yfinance-backed).
- Valuation CLI with model selection (`dcf` / `reverse_dcf`) and optional FX conversion.
- Unit tests for import, mapping, fundamentals provider, valuation models, and valuation service.

Not included in current code:

- Broker API integrations (for example Saxo).
- Live portfolio pull from broker endpoints.

## CLI flow (import -> valuate)

Run from the package root where `pyproject.toml` is located:

```bash
cd StockAdvisor
pip install -e .
```

### 1) Import Nordnet report

Converts a Nordnet report file into normalized holdings JSON.

```bash
python -m stockbot.cli.import_nordnet_report \
  --report ../reports/nordnet_report.csv \
  --out data/holdings_raw.json
```

### 2) Apply ticker mapping

Maps holding names to tickers using your local mapping file.

```bash
python -m stockbot.cli.apply_ticker_mapping \
  --holdings data/holdings_raw.json \
  --mapping data/ticker_mapping.json \
  --out data/holdings_mapped.json
```

### 3) Fetch fundamentals

Fetches fundamentals for mapped holdings and saves them to JSON.

```bash
python -m stockbot.cli.fetch_fundamentals_for_holdings \
  --holdings data/holdings_mapped.json \
  --out data/fundamentals.json
```

### 4) Valuate selected tickers

Runs valuation using holdings prices + fundamentals.

```bash
python -m stockbot.cli.valuate \
  --fundamentals data/fundamentals.json \
  --holdings data/holdings_mapped.json \
  --tickers AAPL,MSFT,NVO \
  --target-fcf-margin 0.2 \
  --forecast-years 10
```

### Optional: force a valuation model

```bash
python -m stockbot.cli.valuate \
  --fundamentals data/fundamentals.json \
  --holdings data/holdings_mapped.json \
  --tickers AAPL \
  --model-override dcf
```

### Optional: override exchange rates

```bash
python -m stockbot.cli.valuate \
  --fundamentals data/fundamentals.json \
  --holdings data/holdings_mapped.json \
  --tickers NOVO-B.CO \
  --exchange-rate DKK:USD=0.145
```

---

## Data files used in the flow

- `data/ticker_mapping.json` – manual name->ticker mapping input.
- `data/holdings_raw.json` – generated by Nordnet import CLI.
- `data/holdings_mapped.json` – generated by mapping CLI.
- `data/fundamentals.json` – generated by fundamentals CLI.
